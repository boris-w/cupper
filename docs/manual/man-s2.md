# MAN-S2：审批与提问

- 场景：PRD S2。agent 要执行越界命令时出现审批，按 Enter 批准、Esc 拒绝，范围选项由 agent 给出；agent 要我做选择或确认计划时出现提问；窗口不在前台时收到系统通知。
- 对应需求：AP-1 至 AP-5，以及设计 5.7.8 的请求面板规则（RP-1 至 RP-12）。假 agent 的自动化版本是 E2E-S2（T170）；按键的细节另由 MAN-keyboard 覆盖。
- 共同约定见 [README.md](README.md) 第 4 节。每一步 Claude、Codex 各走一遍，结果分两列。

## 准备

- 会话的权限模式用会请求审批的那一档：Claude 用 `default`，Codex 用默认的工作区模式（不开网络访问）。
- 需要触发审批时，让 agent 执行一条在这一档下必须批准的命令，例如在工作区之外写一个临时文件。不要用会改动系统设置或删除数据的命令。

## 步骤

| # | 操作 | 预期与通过条件 | 依赖 |
|---|---|---|---|
| 1 | 让 agent 执行一条需要批准的命令 | 请求面板替换输入框的位置。选项带编号，文案和范围选项都与 agent 给出的一致（AP-2）。会持久生效的选项标"需要确认"。会话显示"需要处理" | — |
| 2 | 面板就绪后按 **Enter** | 命令执行，记录行显示"已批准"，面板收起，输入框回来 | — |
| 3 | 再触发一次，按 **Esc** | 记录行显示"已拒绝"，agent 收到拒绝后继续或结束本回合 | — |
| 4 | 再触发一次，按持久选项的编号（如"总是允许"） | 弹出原生确认框，默认按钮是"取消"。点取消后请求仍在等待；再选"仅本次"完成 | — |
| 5 | 再触发一次，在面板的自由输入行写"换个办法"并提交 | 先完成拒绝，再发出这条消息；用户消息上标明"附于对 … 的拒绝"（RP-12） | — |
| 6 | 让 agent 动手前先给出计划并请我确认（Claude 用 plan 模式，在输入框底栏切换；Codex 用它支持的提问方式） | 面板显示提问或计划确认；会话显示"需要处理"。回答或确认后 agent 继续（AP-5） | T141（模式选择器） |
| 7 | 触发审批前先切到别的 App，等请求到达 | 收到系统通知，通知上没有"批准"按钮。点通知：Cupper Local 来到前台，跳到这个会话，焦点不在请求面板上（5.7.8）。回合结束时也收到通知 | T150 |
| 8 | 审批等待时，在终端用自用构建的 CLI（`cupper-local repl`）先 `elevate --scopes approve`，在 Cupper Local 弹出的确认框里批准，再用 `pending` 查到请求编号、`approve` 回答它 | 窗口里的面板自动收起，记录行写明已在别处处理；再在窗口里按 Enter 不会重复回答（AP-4） | — |

## 收尾

- 删掉第 1 至 5 步留下的临时文件。
- 第 4 步如果误选了持久选项，到 agent 自己的权限配置里删掉多出的规则：Claude 在项目的 `.claude/settings.local.json`，Codex 在它的配置里。
