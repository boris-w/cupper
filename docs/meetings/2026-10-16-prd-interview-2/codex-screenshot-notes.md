# Codex 界面截图观察笔记

- 来源：用户提供的截图，内容是 ChatGPT 桌面 App（macOS）的 Codex 视图，中文界面，亮色主题，截于 2026-10-16
- 原图：`.private/references/codex-ui-2026-10-16-main-light.png`。原图含有个人和工作信息，只保存在本地，不提交到仓库（见 `.gitignore`）
- 用途：补充 R01 中缺少一手资料的视觉部分，作为 PRD 和设计阶段的参考

以下描述只记录界面结构和样式，不记录截图里的会话内容。像素数值按 2 倍屏折算，都是估计值。

## 整体布局

从左到右分四列：

1. **图标栏**：窄条，约 40pt 宽。上部依次是首页（当前选中）、历史/时钟、一个圆形图标、"更多"、一个 Git 分支图标；底部是一个蓝色的下载图标（推测是"有可用更新"）和设置齿轮。**R01 没有提到这一栏**。R01 列出的 Skills、Scheduled、Code Review 等入口，推测就收在这一栏里（图标含义是推测）。
2. **侧边栏**：约 170pt 宽，浅灰底色。
3. **会话区**：白底，内容居中，最大宽度约 520pt。
4. **右侧任务面板**：一张浮起的圆角卡片，**不是贴满整个高度的面板**。

标题栏和窗口控件融为一体，没有单独的工具栏：

- 左侧：红黄绿三个窗口按钮、后退和前进、侧边栏开关。
- 中左：文件夹图标加会话标题。
- 右侧："…"菜单、任务面板开关（当前为高亮选中）、展开按钮，以及一个带数字"1"的窗口图标（推测是窗口或标签计数）。

## 侧边栏

- 顶部：标题"Codex ⌄"（产品切换下拉），右侧是铃铛（Activity）和搜索。
- "新聊天"按钮，带编辑图标。
- "置顶"分组：组标题是灰色小字，下面是置顶的会话。
- "项目"分组：
  - 项目行：文件夹图标加项目名。有一个项目的图标是绿色扳手，推测是自定义图标或特殊状态。
  - 会话行：缩进挂在项目下，没有图标，单行显示，超长时截断。
  - 当前会话：浅灰色圆角高亮。
- 在 cupper 里，"Codex ⌄"的位置可以放 agent 或工作区切换（与 R01 第二节的建议一致）。

## 会话区（消息流）

- **用户消息**：靠右的浅灰圆角气泡。长消息默认折叠，底部有"显示更多 ⌄"。
- **回合耗时**："用时 8m 31s ⌄"，是一个可折叠的标题，后面跟一条细分隔线，把这一回合的工作过程收在一起。
- **助手正文**：不加气泡，直接排在白底上，深色文字，行距宽松。
- **活动日志**：每行是图标加一句过去时的灰色摘要，单行显示，超长省略。例如：
  - "已读取 <文件>"
  - "已列出 <目录> 中的文件"
  - "已在 . 中搜索 <关键词>"
  - "已运行 <命令>"（终端图标）
  - 一组操作合并成一行汇总，例如"编辑了文件读取文件运行了命令 ⌄"，可以展开。
  - 列表底部做了渐隐遮罩。
- **回到底部按钮**：圆形，浮在输入框上方居中，带向下箭头。

## 输入框

- 大圆角矩形，边框和阴影都很浅。占位文字是"与 Codex 协作"。
- 底部一行：
  - 左侧：一个"+"（附件），以及权限模式按钮"帮我批准"（即 Approve for me），带图标。
  - 右侧：一个环形进度指示（推测是运行状态或上下文用量）；模型名加推理强度（"<模型> 极高"），带下拉箭头；圆形发送按钮。
- 与 R01 的差异：
  - 权限模式在输入框**内部**的底部一行，不在输入框下方。
  - 已有会话的页面上看不到 Work in 和 Worktree 控件，推测这些只在新建会话时出现。

## 右侧任务面板

一张圆角卡片，分成两节：

- "输出内容 +"：空状态显示"创建文件或站点"。
- "来源 +"：列表项是图标（文件、链接）加单行文字，底部有"查看全部"。

这和 R01 中"任务侧栏（计划、来源、生成文件、摘要）"的描述对得上。

## 视觉风格

- 亮色主题：主区域白底，侧边栏和图标栏是浅灰（大约 #F5F5F5 到 #F0F0F0），二级文字是中灰。
- 大圆角：卡片、气泡、输入框的圆角大约 12–16pt。
- 边框极少，靠底色深浅和留白区分区域，整体信息密度适中。
- 字体：系统字体（SF Pro，中文用苹方）。
- 界面已本地化为简体中文。cupper 需要支持中文界面。
