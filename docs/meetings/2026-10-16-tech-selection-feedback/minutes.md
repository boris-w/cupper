## 讨论要点

用户回复：

> U-T1 不用考虑低版本。最近两三年就可以了
>
> U-T2 还有什么框架选择, 可以看看比如codex等用的什么,待讨论
>
> U-T3 嗯

编排者的理解：

- **U-T1**：只需支持最近三年的 macOS，也就是 macOS 14（2023）、15（2024）、26（2025）。所以最低版本定为 macOS 14。用户本机是 macOS 26.4。
- **U-T2**：用户没有直接回答"安装包 150–300 MB 能否接受"，而是希望先拓宽桌面框架的选择范围，看看 Codex 等同类产品用的是什么框架，再讨论决定。因此：
  - ADR-03 从"提议"退回到"讨论中"；
  - 新派调研任务 R04；
  - R04 的结果回来后，先和用户讨论，再定 ADR-03。
- **U-T3**：接受 M2 后台常驻时系统提示"已添加后台项目"。
- **U-T4**（是否提供"可信 CLI 凭据"）和 **SP-1、SP-2、SP-4 的运行许可**：用户本次没有回复，继续待定，不视为同意。
