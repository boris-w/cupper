## 讨论要点

用户回复：

> U-T1 不用考虑低版本。最近两三年就可以了
>
> U-T2 还有什么框架选择, 可以看看比如codex等用的什么,待讨论
>
> U-T3 嗯

编排者的理解：

- **U-T1**：只需支持最近三年的 macOS，也就是 macOS 14（2023）、15（2024）、26（2025）。所以最低版本定为 macOS 14。用户本机是 macOS 26.4。
- **U-T2**：用户没有直接回答"安装包 150–300 MB 能否接受"，而是希望先拓宽桌面框架的选择范围，看看 Codex 等同类产品用的是什么框架，再讨论决定。因此：
  - ADR-03 从"提议"退回到"讨论中"；
  - 新派调研任务 R04；
  - R04 的结果回来后，先和用户讨论，再定 ADR-03。
- **U-T3**：接受 M2 后台常驻时系统提示"已添加后台项目"。
- **U-T4**（是否提供"可信 CLI 凭据"）和 **SP-1、SP-2、SP-4 的运行许可**：用户本次没有回复，继续待定，不视为同意。

编排者的理解与决策：

| # | 决策 |
|---|---|
| D4 | 新增工程原则：**不为兼容旧系统写任何兼容分支或补丁代码。需要新版本系统才有的 API 时，直接提高最低版本。** 最低版本目前仍是 macOS 14，以后按需提高。这条原则写进 `CLAUDE.md` 和设计文档 |
| D5 | U-T4：M1 不提供"可信 CLI 凭据"，写入 ADR-05 |
| D6 | 用户许可 SP-1、SP-2、SP-4 使用本机已登录的 Claude Code 和 Codex 运行真实会话（会消耗少量额度）。SP-4 拆成 SP-4a（宿主骨架）和 SP-4b（macOS 本地安全实测）。会改动系统设置或弹出系统授权框的项目（注册 LaunchAgent、TCC 授权归属、通知身份）不在这次实测范围内，留到 M2 前、用户在场时再做（SP-10） |
| D7 | 桌面框架由编排者根据 R04 的结果直接给出结论（ADR-03） |
