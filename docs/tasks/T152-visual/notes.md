## 截图阈值

保持 Playwright 默认的逐像素阈值 0.2，不改配置。悬停底色、选中行这类相差几个色阶的差异，截图比不出来，改用 DOM 断言（元素的 class 或计算后的样式）覆盖。调严阈值会让字体抗锯齿上的细小差别也报错，基线会频繁重做。
