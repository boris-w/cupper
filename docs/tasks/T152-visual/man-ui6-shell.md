# MAN-ui6-shell 检查表（作者与本机 Codex 并排比对）

- 用例：MAN-ui6-shell（设计 5.7.4 的人工评审 MAN-ui6，T152）
- 准备：
  - cupper 用含 T152 的构建；Codex 用本机的 ChatGPT.app。
  - 两个窗口都是默认的 1280 × 820。
  - 两边都打开一个有几轮对话的会话，左侧边栏宽度不动（cupper 默认 288；Codex 默认 340，含 52 宽的导航栏）。
  - 同一个桌面背景，同一个主题。亮色、暗色各比一遍。
- 记录：每项写"一致 / 不一致（差在哪）"。不一致的项附截图，截图不提交进仓库（P-20）。

## 1. 窗口与顶栏

| # | 比对项 | 看什么 | 结果 |
|---|---|---|---|
| 1.1 | 交通灯 | x = 16，在 44 高的顶栏里垂直居中 | |
| 1.2 | 缩放后的交通灯 | 菜单"放大"两次（⌘+ 或 ⌘=）、"缩小"一次（⌘−）、"实际大小"（⌘0），每一步后交通灯仍在顶栏垂直居中 | |
| 1.3 | 缩放的快捷键 | ⌘= 和 ⌘+ 都放大，⌘− 缩小，⌘0 复原；每步的幅度与 Codex 相同 | |
| 1.4 | 顶栏高度 | 44；侧边栏开关、右侧按钮组与交通灯在同一条中线上 | |
| 1.5 | 顶栏底色 | 半透明侧边栏打开时，顶栏透出桌面材质，与侧边栏连成一片；下方会话区是不透明的底色 | |

## 2. 半透明侧边栏

| # | 比对项 | 看什么 | 结果 |
|---|---|---|---|
| 2.1 | 材质 | 侧边栏透出 `menu` 材质，换桌面背景时颜色跟着变；亮色、暗色都比 | |
| 2.2 | 关掉开关 | 设置 → 外观 → "半透明侧边栏"关掉后，侧边栏和顶栏变成不透明（亮色 #F6F6F6，暗色 #141414） | |
| 2.3 | 降低透明度 | 系统设置 → 辅助功能 → 显示 → "降低透明度"打开后，cupper 的侧边栏变成不透明，与关掉开关时一样 | |
| 2.4 | 窄窗口 | 窗口窄于 768 时侧边栏浮在内容上，是不透明的 | |

## 4. 侧边栏与侧边面板

| # | 比对项 | 看什么 | 结果 |
|---|---|---|---|
| 4.1 | 拖动范围 | cupper 侧边栏能拖到 188–468；Codex 左栏 240–520，扣掉 52 的导航栏后应当对得上 | |
| 4.2 | 侧边面板开合 | 点"切换侧边面板"，面板宽度在 0.5 s 里弹性展开、收起，会话区跟着变宽变窄；与 Codex 的手感比 | |
| 4.3 | 减弱动态效果 | 系统打开"减弱动态效果"后，面板直接出现、消失 | |

## 5. 回到底部按钮
