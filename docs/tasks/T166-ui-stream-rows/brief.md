## 范围

**做**（计划 T166 一行；设计 5.7.4 的消息流、5.7.8 的"Markdown 与不可信内容"与"样式"、5.7.10）：
1. **助手正文**（streamdown 2.7.0，Apache-2.0，T082 执行者核对过）：
   - 显式给出插件列表，关闭 `rehype-raw`（不渲染原始 HTML），再做白名单清洗；
   - 只放行 `http`、`https` 链接，点击经 `ShellAPI.openExternal`；
   - 不放行任何图片前缀，不允许 data 图片，远程图片显示为链接；
   - Markdown 排版参数按 5.7.10。
   - 代码高亮、Mermaid、数学公式这些插件不装（高亮是 T143；Mermaid 是 P1）。
2. **ANSI**：命令输出里的 ANSI 颜色只映射到固定的 class。agent 的字符串不能进入 `<style>`、`insertRule` 或 CSS 自定义属性。
3. **工具单行摘要**：图标、过去时文案（经 `@cupper/i18n` 按语义码组织，例如 `{tool_kind: read, paths: [a.rs]}` 显示为"已读取 a.rs"）、运行中的闪光、活动组的汇总与展开、命令输出块。
4. **思考**："正在思考""已思考 {时长}"。
5. **提示与错误**：警告框（T128 的 `Alert`），文案按语义码。
6. **登记进 T082 的行注册表实例**。

**不做**：行列表与锚点、回合标题、用户气泡、未知占位（T082）；请求记录行（T165）；代码高亮、计划、恢复指引、折叠（T143、T146）；改动卡片（T132）。
