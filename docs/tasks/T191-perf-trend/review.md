## 逐项意见

1. **共用函数**：`append` 不读机器信息，单元测试可以直接调用；`trend` 负责取日期、提交、版本和机型。`perf` 与 e2e 两个作业共用同一套统计、追加、判定的代码，判定规则没变。
2. **e2e 写历史的时机**：只在 `ci e2e`、`ci nightly` 下设 `CUPPER_PERF_OUT`，`ci pr` 的冒烟不写；全部用例通过后才写；样本在用例的断言通过之后才记。失败的测量不会进入趋势。
3. **指标名**：窗口在屏幕上与被遮住分成两个指标，单位与已有的行一致；绝对闸门 p99 < 5 ms 仍由用例自己断言。
4. **每晚多花的时间**：约 5–7 s，比 T117 估的 1 分钟少，有实测数据。
