# T266 笔记

## 开工前的估算（2026-11-16）

### 做法（按模块）

1. **宿主与协议**：
   - 设置加两个键 `sessions.default_permission.claude`、`sessions.default_permission.codex`，类型 `Option<String>`，`null` 表示沿用 CLI 配置；
   - 宿主默认值为 `null`，不算安全键，在 `policy::method` 的穷举里登记为普通键；
   - 空字符串拒绝；
   - 跑 `pnpm gen`；协议和宿主各补一条测试。
2. **新建会话页的预选**：
   - 接在 T144 留的入口 `useNewOptions(agent)` 上，`permission_mode` 的取值顺序是"用户的选择 → 默认权限（在缓存的能力里时）→ agent 自己的值"；
   - 有效的默认权限同样进 `chosen`，所以 `session/create` 会带上它；是完全访问时，照样走 `create_session` 原生确认。
3. **设置页"默认权限"**：
   - "通用"里，Claude 和 Codex 各一行；
   - 选项是"沿用 CLI 配置"，以及 `useCached(agent)` 里该 agent 的权限模式。
   - 设置页**不触发探测**：给 `useCached` 加一个参数，只读缓存。否则一打开设置页就会拉起 Codex 的适配器和用户的 MCP。缓存为空时，只有"沿用 CLI 配置"一项，并提示"新建一个会话后才有可选的模式"。
   - 存下的模式已不在能力里时，提示"已按沿用 CLI 配置处理"。
4. **Q45 启动预选**：
   - 会话页挂载时，把它的项目记进 UI 偏好 `newSession.lastProject`；
   - `useSessionState` 解析新建会话页的项目：上次的项目还在就用它，否则用列表里的第一个；
   - `NewSessionPage` 和 `@` 文件引用都改用这一处。
5. **顶栏**：
   - 会话页的标题区显示会话标题，没有标题时写"新会话"；
   - 标题旁是 agent 标识（12 号 tertiary 色，1px 描边，`--radius-xs`）；
   - worktree 会话再加"· 分支名"。
   - 写成接收 `SessionSummary` 的组件，便于单元测试。
