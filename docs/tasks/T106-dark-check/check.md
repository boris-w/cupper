### Q36：左栏默认 340 是否包含导航栏

**结论：包含。cupper 默认 288 正确；拖动范围需要按"不含导航栏"换算。**
- 〔包〕左栏宽度存为偏好 `sidebar-width`：默认 340，限制在 240 到 min(520, 窗口宽 − 240) 之间，最小值常量 240，侧边栏断点 `(min-width: 768px)`。
- 〔截图〕导航栏宽 52 pt（含 0.5 pt 分隔线）。
  - `running-with-text` 那张：整个左栏 340 = 导航栏 52 + 侧边栏 288。
  - 其余五张：左栏 290 = 52 + 238。238 小于下限 240，说明存下来的宽度算的是含导航栏的整个左栏，而不是侧边栏本身。
- 所以：Codex 的 240–520 和 340 都含 52 的导航栏。cupper 没有导航栏，等价的侧边栏宽度是默认 288、范围 188–468、主区至少 240。

### Q37：暗色取值

**结论：暗色下输入框底色是 #363636。截图上看得到的暗色 token 都与推算值一致（差 ≤ 1），可以去掉〔推算〕。**
- **输入框底色的两条规则**〔包〕：
  - 规则一，不分主题：`.ComposerLayoutRoot[data-composer-surface-variant=default|opaque]` 取 `--color-surface-elevated-secondary`（暗色 #2D2D2D）。
  - 规则二，只在暗色下生效：在 `[data-theme=dark]` 下，或者没有 `data-theme` 但处于暗色（`@container style(--theme-variant:dark)`）时，对 variant 不是 inline / secondary / document、并且没有在拖放的输入框，取 `--color-background-composer-surface`。这个变量等于 `var(--app-color-background-elevated-primary-opaque, var(--color-surface-elevated))`。
  - 规则二选择器的优先级更高，所以暗色主题下默认的输入框取 elevated-primary-opaque。
  - 拖放中改用 surface-elevated-secondary，或它的 50% 透明。

### Q38：会话行尾有没有相对时间和 diff 统计

**结论：没有。**
- 〔包〕Codex 本地会话行的 `metaContent` 传的是 `undefined`，并且设了 `statusIndicatorReplacesMeta: true`：行尾那一格只用来放状态。
- 〔截图〕
  - 平时：行尾什么都不显示。
  - 运行中：行尾是转圈。
  - 审查 PR 的会话：行尾是紫色的 PR 图标。
  - 悬停：行尾出现固定和归档两个按钮，同时在行的右侧弹出悬停卡片。卡片第一行是标题和图标，右侧是相对时间（"N 个月前"）；第二行是文件夹图标加项目名。卡片底是 surface-elevated（暗色 #2D2D2D）。
- 〔包〕悬停卡片的数据有：时间戳、项目、环境、状态行（需要批准、需要输入、系统错误等）、自动化。
- cupper 要不要做悬停卡片，由编排者定。

### Q39：输入框为空时按 ↑ 是否恢复上一条

**结论：恢复〔实机〕。**
- 〔实机〕输入框为空时按 ↑，会填回上一条发出的消息。
- 〔包〕没有定位到输入框里 ↑ 的按键处理：检索了按键表和历史相关的名字，都没有找到。
  - 只找到"编辑最后一个用户回合"（`editLastUserTurn`、`onEditLastTurnMessage`），那是消息上的就地编辑，另一个功能。
  - 所以包里看到的和实测并不矛盾，只是没找到对应代码。
- **留一个细节**：↑ 填回之后再发送，Codex 是作为新消息发出，还是改写上一个回合，包里判断不了，需要作者再试一次。cupper 的 CP-1 写的是作为新消息发送。

### Q41：Codex 的数字键是否"选中即提交"

**结论：是〔实机〕〔包〕，与 cupper 的 RP-5 一致。**
- 〔实机〕审批面板（单选）里按数字键，马上提交，不需要再按 Enter。
- 〔包〕请求面板（`requestInputPanel.*`，提问和审批共用；自由输入一项的占位是"No, and tell ChatGPT what to do differently"）的键盘处理：
  - 按 1–9 选中第 n 项。单选时立即提交；开着动画时先高亮 180 ms 再提交。
  - 多选时只切换选中。
  - 编号等于"选项数 + 1"时，焦点移到自由输入行。
- 包里看到的和实测一致，没有差异。
