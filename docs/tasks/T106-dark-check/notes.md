## 量尺寸的口径

- 左栏宽度：在空白行上横向扫描颜色的突变处，得到导航栏、侧边栏和主区的分界。
- 圆形按钮：取与背景色差超过阈值的像素的外接框；按钮被正文压住的一侧不计。
