- 分支：`feat/T086-ui-composer`
- 依赖：T080、T084、T118、T128（都已合并）；长文本经 blob 上传要用 T029（并行进行中，见"工作方式"）。T083（请求面板替换输入框）、T085（新建会话页）、T091 依赖本任务

## 背景

外框给输入框留了两个插槽（`newSessionComposer`、`sessionComposer`，T084）；状态层（T080）里已有按会话的草稿、附件和滚动位置（`useUi()`）；Toaster 与特权操作反馈（T081）也已就位。本任务按 Codex 的样式做输入框和排队消息，接到这两个插槽上。

## 范围

**做**（计划 T086 一行；设计 5.7.4 的输入框与排队消息、5.7.7 的快捷键、5.7.10；ui-spec 4.5）：
1. **输入框**：
   - 外形与底栏按 5.7.4、ui-spec 4.5；
   - 发送按钮三态（可发送、运行中、不可用）；
   - 附件条；
   - 草稿、附件按会话存在 `useUi()` 里。
2. **按键**（5.7.7）：
   - Enter 发送，⇧Enter 或 ⌥Enter 换行；"发送快捷键"可设为 ⌘Enter；
   - 输入法组合过程中按 Enter 不发送（`isComposing` 或 keyCode 229，CP-1）；
   - **Esc 的处理顺序**与"运行中按两次 Esc 停止"：第一次进入确认状态，第二次才停止（`session/interrupt`）；先关闭输入框里的浮层。
3. **运行中发送**：M1a 没有 Steer，一律排队（`session/send` 的回复为 `queued`）。
4. **长文本**：超过帧预算的文本经 blob 上传，用 `text_blob` 发送。要用 T029 的 `blob/put`，见"工作方式"。
5. **排队消息**：预览、暂停与"继续"（`session/queue_resume`）。插话和排队消息的编辑不做。
6. **扩展点**：底栏左右两组插槽和弹出层挂载点，供 M1b 的 T140、T141、T142、T145、T149 只新增文件（计划 1.x 的"输入框"一条）。
7. **DOM 标记**：`data-send-state` 等，供 e2e（T090、T091）断言。

**不做**：插话、排队消息的编辑（T140、T149）；请求面板（T083，它会在同一个插槽位置替换输入框，接口由本任务的插槽约定）；`@` 与 `/` 的菜单（M1b）。
