## 做了什么

新增 `docs/01-prd-ui.html`，是一个单文件 HTML，约 1,500 行。用浏览器直接打开就能看。

- **1 概览**
  - 一句话定位；用户、G1–G3、S1–S7 一览表（标出里程碑，并链接到对应的场景图）。
  - 里程碑：一张 mermaid 图，加一张表，覆盖 M1a、M1b、发布（推迟）、M2、M3、M4。每个里程碑写明交付什么、退出标准、界面上看得到的变化。
  - "这份页面怎么读"：编号、里程碑的来源、示意文案、虚线等于 M1b 之后才交付、状态点颜色、"待定 Qn"的含义。
- **2 主界面全景（M1b）**：三栏线框，共 35 个编号，下面是对照表（编号、元素、说明、需求、里程碑）。另外列出了图里没画、但全局存在的元素：Toaster、"正在重新连接"、"无法验证宿主"。
- **3 逐个界面**：每个界面都有线框、编号和需求对照表。
  - 3.1 新建会话：附权限模式与审批档位表（设计 5.6.5、5.8.2）。
  - 3.2 消息流，分四张图：
    - 运行中的回合；
    - 结束后的回合（折叠，以及已取消、已中断的回合）；
    - 计划与待办：Codex 的待办清单对比 Claude 的 Markdown 计划，口径按 Q12；
    - 错误、提示与晚到的输出。
  - 3.3 审批卡片：Claude 和 Codex 的待处理卡片，以及 6 种状态。
  - 3.4 提问卡片与计划确认卡片：选项按 option_id 注明效果。
  - 3.5 输入框：空闲和运行中两张图。
  - 3.6 审查面板：附归档时清理 worktree、恢复会话的对话框。
  - 3.7 四种原生确认框，画成 macOS 系统对话框：信任项目、切到完全访问、"总是允许"类选项、CLI 提权（分开列出"宿主核实的信息"和"申请方自述"）；另附其他走原生确认的操作表。
  - 3.8 设置页：Agent 状态一张图，其余分区一张图，含"本地鉴权较弱"的说明。
  - 3.9 系统通知。
  - 3.10 cupper-cli 的终端示意（用 `<pre>`）。
  - 3.11 M1a 最简界面的线框，以及 M1a 与 M1b 的逐区域对比表。
  - 3.12 M3 iOS 端：5 个手机画面、桌面端的配对与设备管理、SEC-9 权限边界表、前提与限制、M4 新增的功能。
- **4 关键场景**：S1–S7 各一张 mermaid 流程图或时序图，注明里程碑、对应界面和需求编号。
- **5 需求总表**：PRD v1.2 的全部需求，按 AG、PS、CP、MS、AP、GT、UI、MB、SEC、RL、NFR 分组，每行写编号、一句话、优先级、里程碑、出现在哪个界面（带链接）。
- **6 边界**：不做什么、自用阶段的安全须知、与 Codex 桌面版的差异。

**响应编排者中途的补充**：线框的全部尺寸、间距、字号、圆角、线宽和颜色，都集中写在 `<style>` 开头的 `:root` 变量里，均为中性占位值。CSS 规则里不再有写死的 px 或颜色值，HTML 里也没有内联样式。R06 的 `ui-spec.md` 到了之后，替换这些变量就行，再按规格调整组件结构和文案。

  - 设计没有规定的细节都在图里标了"示意"，并在表里写明"设计未规定"：
