## 背景

T144 发现：宿主每次会话接上 agent 时都会刷新 `agents/capabilities` 的缓存，但不发事件；界面的缓存查询 `staleTime` 是 Infinity，只在 `agents.updated` 或重新连接时失效。所以 agent 升级后的新命令、新模型，新建会话页要等重连才看得到。T144 只处理了首次使用时缓存为空（按设计 5.6.7 探测一次）。

## 范围

**做**（计划 T268 一行；设计 5.6.7、5.3 的协议规则）：
1. 宿主在能力缓存的内容变化时发事件，不变时不发。先看是复用 `agents.updated` 合适，还是加一个附加式的事件（例如带 agent 名），按 5.3 的协议规则（附加式、`SCOPE`、生成物）定，在估算里提出来。
2. 界面收到后让对应 agent 的缓存查询失效（`["agents/capabilities", agent]`），新建会话页随之更新。
3. 宿主集成测试：缓存变化发事件、不变不发；界面单元测试：收到事件后重新读。

**不做**：新建会话页的其他改动（T266）。
