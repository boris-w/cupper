## 逐项意见

1. **上报走窗口自己的连接**：宿主按连接记在场，只采信 `desktop_ui` 的，所以从窗口的 `HostClient` 发，主进程的 control 连接不发；每条新连接补报一次，靠 `HostClient` 每次 attach 的 `ready`，不另判断。
2. **评审查出 iframe 的问题，已修**：审查文档是独立 origin 的 iframe，焦点进去时顶层 window 收到 `blur`，原写法会上报不在前台，用户在审查文档里写评论时它的回合完成会弹通知。改为 blur 之后在下一个 task 用 `document.hasFocus()` 复核；执行者先在跨进程 iframe 上实测了这一点，E2E 也补了"焦点在 iframe 里不弹通知"。
3. **E2E 没有 sleep**：用宿主写下的 running、非 running 摘要做正面屏障，再用"切走之后有通知"做正向对照。
