## 逐项意见

1. **分页按设计的顺序**：已归档会话排在 agent 状态前面，默认分页随之变成已归档会话；T147 把通用、通知排到最前之后，默认分页自然变成"通用"，与设计 5.7.4 一致。错误条目跳 agent 状态带着分页参数，不受影响。
2. **共用 `CommandButton`**：T151 的"重启"和"恢复"共用，删掉了几乎相同的一份。
3. **恢复的反馈**：worktree 会话恢复约需 1 秒，按钮显示进行中；结果用 toast，`read_only` 时注明原因，因为恢复成功后行会立即消失。
4. **安全约束**：标题、项目名、客户端名称和版本经 `escapeInvisible`，只作为文本显示。
