## 逐项意见

1. **`light-dark()` 加 `color-scheme`**：亮暗值只写一处，`data-theme` 固定主题。比写两遍省一半，也不会出现两份取值不一致。认可。
2. **宽度只经 `style={{width}}` 写入**：不进 CSS 自定义属性，也不拼 `<style>` 文本，符合 5.7.8 的样式规则。
3. **自动收起只是不显示**：`sidePanelOpen` 只记用户意图，窗口变宽后自然恢复，不必另存状态。设计好。
4. **布局逻辑写成纯函数**：UNIT-ui-shell-resize 覆盖范围限制、浮层、自动收起与恢复、比例保持、键盘与拖动、store 的读写与跟随。
5. **`HostProvider` 打不开连接时记 `host_unreachable`**：和主进程用同一个语义码，不会一直停在"连接中"。好。
