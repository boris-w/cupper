## 逐项意见

1. **基准取 `merge-base`**：合进分支的 main 已在基准里，不需要逐提交排除；本地 main 比合进来的旧时，改用第一父链上合并提交的第二父。统计净差异而不是逐提交累加，写了又删的行不算两次，与以往汇报的口径一致。

5. **流程**：任务书模板新增"规模"一节和固定格式的停止线，`docs/00-process.md` 的任务生命周期写明"每次提交后跑一次 `cargo xtask size`，推算或实际越线就停下汇报"。
