## 做法

- **基准**：`merge-base 版本 main`。合进分支的 main 已经在基准里，它的改动不算。本地 `main` 比合进来的旧时，取第一父链上 merge 提交的第二父里最新的一个（`merge-base --independent`）。
- **统计范围**：默认统计到工作区，未提交的改动也算，新文件要先 `git add`。`--rev`/`--main` 用来统计过去的状态。
- **停止线**：任务书模板的固定一行 `- 停止线：<n>；硬停止线：<n>` 优先，取最后一行。没有这一行时，读标题含"规模"或"裁定"的节里的自然语言，后出现的数覆盖先出现的，所以补充裁定会覆盖原值。
- **任务书模板**新增"## 规模"一节，写着这一行和"每次提交后跑一次 `cargo xtask size`"。`docs/00-process.md` 的任务生命周期里也写明了。
