## 逐项意见

1. **组件分两层**：`parts.tsx` 只按 props 画，`index.tsx` 只从 store 取数据。交互用例直接测第一层，T080 合并前就能写。结构好。

3. **会话行**：
   - 运行中、出错、未读三种行首标记；
   - `pending_kind` 的两种标签，不认识的 kind 按"需要用户输入"；

   - 都对未知取值有退路。
4. **截图设施的扩展**：mock 宿主对每个订阅回 snapshot 模式，再发一页 `stream/snapshot`，索引流的数据来自夹具。以后的界面任务照用。UI-shell 四张基线的变化只在侧边栏（多了"新会话"和"项目"小标题），预期之内。
