## 逐项意见

1. **不覆盖用户的文件**：`lstat` 加 `realpath` 判定已安装和被占用，悬空的链接、指向别处的链接都算被占用；检查之后才出现的文件靠 `symlink` 的 `EEXIST` 兜住。
2. **位置检查对**：`realpath` 之后必须在 `/Applications` 或 `~/Applications` 之下，从 DMG 或下载目录运行时不装，避免链接指向会消失的位置。
3. **被拒不计入冷却**：返回 `failed`（`unavailable`，带原因和路径），界面给出具体说明；用户没有取消，不该被冷却拦住。
4. **主进程的约束守住**：特权操作只在主进程执行，只经原生确认框，不经 shell，`dialog.showMessageBox` 在调用时才取。
