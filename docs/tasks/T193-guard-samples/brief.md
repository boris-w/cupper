- 派发日期：2026-10-27

- 依赖：T190（已合并）。T151 依赖本任务

## 背景

T190 的守卫 UNIT-proto-absent-not-null 沿导出的 schema 检查样例：非必填属性上不能有 `null`。可它只检查得到样例里出现过的属性：220 个带 `Option` 的属性里覆盖了 135 个，其余 85 个逐个列在 `docs/tasks/T190-absent-not-null-guard/notes.md`。没覆盖到的里面，`ItemUpdated`、`ItemCompleted`、`ToolCall` 是宿主发得最多的事件。M1b 第一次附加改契约的是 T151，在那之前要把守卫补全（计划 v1.3.61）。

## 范围

**做**：
1. 为每个方法的参数与结果类型、每种事件，生成一个"可选字段全填"的合法实例：经 Rust 类型读入再序列化，然后过同一个守卫。
   - 做法由你定：按导出的 schema 生成，或者给类型写最大实例。部分 ID 有格式约束，生成的值要合法。
   - 能复用 T190 的方法类型表，就不要另起一张。
2. 覆盖面统计照旧输出，补完后应接近全部；补不上的列出来，说明原因。
3. 负面样例：挑一个原来没覆盖到的属性（例如 `ToolCall` 的某个可选字段），临时去掉 `skip_serializing_if`，确认守卫现在能抓到。不提交。

**不做**：改契约；改导出时的变换。
