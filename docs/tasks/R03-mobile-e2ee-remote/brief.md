# R03 移动端远程操控与端到端加密方案调研

- 派发日期：2026-10-16
- 执行者：子 agent（技术调研）
- 分支：`research/R03-mobile-e2ee-remote`
- 依赖：无

## 背景

用户的第二个需求是开发移动端，通过移动端操作桌面客户端，并且要支持端到端加密。写 PRD 之前需要了解：已有产品怎么做的，移动端通常能操作哪些功能，端到端加密在架构上有哪些可选方案和代价。见 `docs/meetings/2026-10-16-prd-interview-1/minutes.md`。

## 目标

产出现有产品对比，以及远程连接和加密方案的可选项与取舍。

## 范围

- 做：
  - 现有产品：Happy（happy.engineering）、Omnara、Claude Code 官方的远程或移动端能力、Codex 的移动端能力，以及其他远程操控 coding agent 的工具。逐个说明：架构（中继 / P2P / VPN）、配对方式、加密方案、移动端能做什么、推送通知、是否开源及许可证、能否自托管。
  - 连接方案：中继服务器、P2P（WebRTC 等）、组网工具（Tailscale 等）、局域网直连，各自的优劣。
  - 加密方案：配对和密钥交换（如扫码 + X25519）、消息加密（如 libsodium、Noise 协议）、多设备、密钥轮换与撤销、中继能看到哪些元数据。
  - 端到端加密下的推送通知怎么做（推送内容加密、iOS Notification Service Extension 等）。
  - 移动端常见功能清单：查看会话和实时输出、发送指令、审批权限请求、查看 diff、新建会话等。
- 不做：不写代码，不做最终选型。

## 验收标准

- [ ] 产品对比表：产品 / 架构 / 加密 / 移动端功能 / 开源与许可证 / 自托管。
- [ ] 连接方案和加密方案各有一张取舍表，并说明适用场景。
- [ ] 移动端功能清单，标注哪些是各产品普遍具备的、哪些是差异化功能。
- [ ] 每条事实附来源，标注日期，区分"已核实"和"推测"。
- [ ] 「对架构的启示」一节：从"桌面端先行、移动端平滑接入"的角度，说明这些发现对整体架构意味着什么（作为 PRD 产品-架构对齐会的输入）。
