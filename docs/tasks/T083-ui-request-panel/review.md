## 逐项意见

1. **RP-1 至 RP-9 逐条落实**：
   - 待命期内按键重新计时并吞掉；
   - 只认待命结束后按下的点击；
   - 自动获得焦点的三个条件与 `data-activation`；打字键撤销；
   - 第一下 ⌘Enter 只提示；
   - 编号等于序号、效果未知的选项只能点击；
   - 特权选项只经 `requestPrivileged`、Esc 永远不会选中；
   - 有弹出层时不响应按键。
   - UNIT-request-panel 九条用例用假时钟覆盖了这些规则。
2. **两个实现细节判断得好**：
   - "焦点曾在输入框里"在输入框卸载前写进 `activity`，否则面板挂载时已无法判断；
   - 窗口获得焦点的时间放在 `ShellProvider`，从第一次渲染起记录，否则面板出现之前那次窗口激活记不到，"请再按一次"会错判成撤销。
3. **保守的默认**：
   - "效果未知"一律算特权，键盘无效；
   - 截断的内容只能拒绝（安全 #6）。
4. **agent 文本**一律经 `escapeInvisible` 转义、只作为文本节点渲染。
5. **审阅截图**（系统字体，1280 × 820）：问句、终端框、编号选项、特权选项的标注、"跳过"与带键帽的"提交"，与设计 5.7.4 和 Codex 的样式一致。执行者看图时还修了两处对比度问题。
