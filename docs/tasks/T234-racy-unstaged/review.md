## 逐项意见

1. **根因查得透**：链路是 `write-tree` 回写临时 index 时，按相对路径 lstat，在工作区外 lstat 失败，racy 条目漏了 smudge；回写后 index 的时间戳变新，`add -A` 就看不到改动。证据有三层：
   - 进程级的前后对比；
   - 只把 mtime 恢复回去的对照实验；
   - 纯 git 的最小复现。
   为什么进程内夹具复现不了，也解释清楚了。
2. **修法在根上**：选 A，所有会回写 index 的快照档命令都受益。顶层由 `Layout::read` 保证，单元用例锁住了工作目录。工作区中途消失时的错误映射也补了断言。
3. **用例是确定的**：用 `set_times` 加关 ctime 来构造同一秒，不靠 sleep；关 ctime 的理由写清楚了（否则结果取决于时机）。修复前两组都失败，失败输出写进了汇报。
