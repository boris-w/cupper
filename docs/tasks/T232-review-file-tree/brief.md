## 范围

**做**（计划 T232 一行；设计 5.7.5"文件树"、5.7.7 的 ⌘⇧E）：
1. **文件树**：
   - 默认关闭；头部右侧"显示文件"/"隐藏文件"切换，⌘⇧E 也能切换（菜单命令已注册，在冻结的 ShellAPI 命令联合里）；
   - 行高 28、文字 13、目录吸顶、超长文件名在中间截断；
   - Git 状态用图标表示，不用字母，颜色取新增、删除、修改三色；
   - 顶部"筛选文件…"输入框；
   - 右键菜单：复制路径、在外部应用中打开（UI-0，复用 T126 已有的打开方式）。
2. **文件行上的操作按钮**：只有图标的按钮（ghost 色，28 的圆形），tooltip 写操作名（暂存、取消暂存、还原），按 `ACTIONS[scope]` 显示；还原一律经 RP-11 的确认控件（`askRevert`，`source: "view"` 的规则：不抢焦点）。hunk 级的按钮在 diff 视图里，归 T131。
3. **点击文件跳转**：`store.set({ focus: { path, line, seq: (focus?.seq ?? 0) + 1 } })`；T131 之前的占位视图能滚到对应文件即可。
4. **共用组件的小修**（T130 的遗留）：菜单关闭后焦点回到 `ToolbarButton`，它的 tooltip 和焦点环随之出现，用鼠标选完也是这样。改成：
   - 鼠标关闭菜单时，不让 tooltip 因此打开；
   - 键盘关闭时照常把焦点还给触发按钮（无障碍要求）。
   改完去掉截图用例里"先点一下空白处"的绕法。
5. **用例 UI-review-tree**（已登记）：文件树开合、筛选、状态图标、亮暗两种主题；截图基线只用 `ui-baseline` workflow 生成，你只取新增的和确实受影响的那几张，逐张看过再提交。
6. 附复刻度审阅截图（e2e 构建、系统字体，不进基线）。

**不做**："Git 操作"菜单与提交弹窗（T233）；diff 视图与 hunk 按钮（T131）。
