## 逐项意见

1. **取回的代码原样取回**：`hunks.rs`、`cache.rs` 来自 T120 的 38f85e0、0e1c0f0，两份单元用例也取回了。IT-git-file-diff 不和它们重复，只测真实 git 上从 token 到单位的整条路径，并做了两处变异检查。
2. **缓存的语义清楚**：键是 `diff_token`，值是工作区、tree 对、文件列表和 `Place`，不存补丁；按生成时间过期，不续期；每个工作区最多 32 个；token 不存在、过期或不属于这个会话的工作区，一律返回 `conflict(stale_diff)`。
3. **锁不跨 await**：`DiffCache` 放在 `std::sync::Mutex` 里，`get` 返回拷贝，锁在语句结束时就放掉。
4. **大 hunk 转 blob**：单个 hunk 超过 `max_inline_bytes`，或者累计快要超过一帧（留 8,000 字节给信封）时，转成 `lines_blob`。
