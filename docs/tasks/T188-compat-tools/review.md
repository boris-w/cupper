3. **剧本结果用穷尽的 `match` 判断**：T187 加了新取值后这里会编译不过，逼着合并的人按裁定补分支，不会悄悄把新取值当成某一种。
4. **compat-framework 进 `ci pr`**：`ci pr` 下只在改了五条兼容套件路径时运行；单独运行或每晚运行时总是执行。路径判断挪进 `ci/git.rs`，与 ui 作业共用。
   - 假 agent 和宿主不在路径表里，认可：它们改坏了执行者的编译，rust 作业照样能发现；行为上的回归由每晚的 compat-framework 发现。
