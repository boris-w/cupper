# T065 B 层金样例运行器

- 派发日期：2026-10-20
- 执行者：子 agent（Rust 工程师）。T052、T165、T168、T067 的执行者接着做（做过录制格式、录制导出和回放）
- 分支：`test/T065-gold-b-runner`
- 依赖：T044、T047（已合并）；T067 的回放刚合并。T066（首批真实录制）之后会产出真实的 B 层录制

## 背景

金样例分两层（设计 5.9.2、5.9.3）：
- **A 层**：提取层的逐帧回放，T053 已做。
- **B 层**（本任务）：进程内的宿主核心（纯核心、写入合并、视图）经内存传输回放录制，虚拟时钟按录制里的 `t` 推进，断言规范化后的协议事件。B 层只用 `source: host` 的录制。真实的 Claude 录制要等 T066，本任务先用假 agent 经宿主产出的录制。

## 范围

**做**（计划 T065 一行；设计 5.9.3 的 B 层与规范化）：
1. **运行器**：
   - 进程内宿主核心，加内存传输；
   - 加按录制 `t` 推进的 `ManualClock`，时间只经 `Clock`。
2. **规范化**：按 `x-id`、`x-time`、`x-path` 把协议事件里的 ID、时间、路径换成稳定的占位，规则照设计 5.9.3。
3. **严格模式**：规范化之后逐条精确比对；不符时给出事件序号和字段路径，照 T067 回放的错误信息风格。
4. **`pnpm test:golden` 的 B 层**：接进 `xtask ci` 里金样例的位置（A 层在哪跑，B 层就跟在旁边）。
5. **首批 B 层样例**：用假 agent 经宿主产出 `source: host` 的录制（T047 的录制导出），覆盖普通回合、审批、取消等几种剧本，连同期望的规范化事件一起入库。录制里不能有本机路径和用户名，过 testdata-scan。

**不做**：真实 Claude 的 B 层录制（T066）；codex 的取消场景（M1b）；宽松比对档。
