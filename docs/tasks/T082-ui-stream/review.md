## 逐项意见

1. **行带数据**：`StreamRow` 的每种行都带着要显示的数据，行组件是 `row` 的纯函数，不必订阅视图。T166 因此能拿造出来的行直接测试和截图。代价是每帧至多重新拍平一次，长会话里是一次线性扫描，可以接受。
2. **拍平**：顺序是回合、条目、尾部、`unknown` 列表。连续同 `group_id` 的工具调用合成活动组；请求条目留作 `request` 行（T165）；不认识的条目种类显示占位。
3. **历史与锚点**：
   - 用第一个回合的编号判断是否还有更早的历史；视图重建后按新的第一个回合重新算游标，不沿用旧游标；
   - 锚点只在被记下的那一行确实被推后时才恢复；新插入行的真实高度由 TanStack 自动补偿。
4. **贴底与 ↓**：24 px 阈值，有用例。
5. **共用注册表**：`streamRows` 与 `registerRow`；`rows/index.ts` 一次性载入全部登记；同一 kind 只能登记一次。
