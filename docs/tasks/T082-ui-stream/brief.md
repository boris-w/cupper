## 背景

会话页现在只有警告框（T137）和输入框（T086），中间的消息流还是空的。状态层（T080）已经能按条目订阅会话流的视图（`useEntry(view, key)`，键如 `item:<id>`、`turn:<id>`、`tail`），行类型注册表（T128）也已就位。本任务把会话流画成 Codex 样式的消息流。

请求面板与请求记录行由另一个执行者在 T083、T165 里做。T165 会在 `rows/` 下建共用的行注册表实例，本任务与它协调（见"工作方式"）。

## 范围

**做**（计划 T082 一行；设计 5.7.4 的消息流、5.7.6 的长会话、5.7.8 的 Markdown 与不可信内容、5.7.10）：
1. **行列表**（5.7.6"长会话"）：
   - 按行虚拟化（TanStack Virtual）：把回合标题、活动组摘要、消息、提示等拍平成行；活动组折叠时只占一行；
   - 顶部"加载更早的历史"（`history/page`）；向前插入历史后视口不跳动（以视口顶部的行为锚点）；
   - 流式增长时贴底；用户向上滚动后停止贴底并显示 ↓ 按钮。
2. **消息类的行**（样式按 5.7.4、5.7.10）：
   - 用户气泡：最大 70%，折叠与"显示更多"，悬停"复制"；
   - 助手正文：streamdown 的配置与 Markdown 排版参数；
   - 工具单行摘要：图标、过去时文案（经 `@cupper/i18n` 按语义码组织）、运行中的闪光、活动组的汇总与展开、命令输出块；
   - 思考："正在思考""已思考 {时长}"；
   - 提示与错误：警告框（T128 的 `Alert`）；
   - 带状态的回合标题："已处理""你在 … 后停止了""已中断""失败"，不折叠；
   - 未知事件的占位（视图的 `unknown` 列表，T072 的交接），位置由本任务定。
3. **Markdown 与不可信内容**（5.7.8）：
   - streamdown 关闭 rehype-raw（不渲染原始 HTML），再做白名单清洗；
   - 只放行 `http`、`https` 链接，链接经 `ShellAPI.openExternal`；
   - 不放行任何图片前缀，不允许 data 图片，agent 输出里的远程图片显示为链接；
   - ANSI 颜色只能映射到固定的 class，agent 的字符串不能进入 `<style>`、`insertRule` 或 CSS 自定义属性。

**不做**：
- 请求记录行（T165）；
- 代码高亮、计划、恢复指引、折叠（T143、T146）；改动卡片（T132）。
