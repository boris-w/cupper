## 逐项意见

1. **写条目的位置统一**：三种失败都在回合机的 `end()` 里写，位置在 Settle 之前，每个回合至多一条，不需要另记标志。"prompt 先失败、适配器随后退出"这种情形，用例确认只写一条。
2. **映射穷举**：`guidance()` 对 `FailureCode` 穷举匹配，新增取值时编译就会失败。`retryable` 只在 guidance 为 `retry` 时为真，含义写得清楚。
3. **发现并纠正了一处与注释不符的行为**：`AgentError.message` 的注释写着"截断、脱敏"，分类器其实只截断。脱敏放在会话 actor 这个唯一入口，注释改成了实际行为。
4. **顺序正确**：error 条目之前先给合并器一个 `Interject`，缓冲的文字先写出，和交互请求的做法一致。
