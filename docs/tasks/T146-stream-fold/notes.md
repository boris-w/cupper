## 预计会变的现有基线

折叠标题挪到用户消息之下，完成的回合写"用时 {时长}"并折叠，所以 UI-stream-markdown、UI-stream-tools、UI-code-highlight、UI-plan（两种）、UI-error 的 12 张（各亮暗两张）都会变；其他页面没有回合，应该不变。

## 宿主怎样填 `final_item_ids`（2026-11-04 核对，编排者裁定）

- 规则在 `orchestrator/grouping.rs`：最后一个过程条目（工具调用、活动组里的思考）之后的 agent 消息；没有过程条目时是全部 agent 消息；其他条目不清空也不加入。规则在 coalescer 里，与 agent 无关，Claude 和 Codex 一样。
- `stop_reason` 除 `Cancelled` 外都是 `completed`；`cancelled`、`failed` 按同一规则；宿主重启补发的 `interrupted` 为空。
- 回合以工具调用收尾时，正常结束的回合 `final_item_ids` 也是空的。编排者选按设计只显示折叠标题（T132 的改动卡片在折叠之外），UI-stream-fold 加了一张这种情形的截图守着；这种情形的显示留给 T148 的复刻度审阅和本机 Codex 比对后再定。
