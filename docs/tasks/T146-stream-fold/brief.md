# T146 消息流增强 II：回合折叠与晚到输出

- 派发日期：2026-11-04
- 执行者：子 agent（前端工程师，ui-core 与桌面）
- 分支：`feat/T146-stream-fold`
- 依赖：T143（消息流增强 I，已合并）。T132（回合改动卡片）、T155（SP-6 场景改写）依赖本任务

## 背景

消息流的基础（行虚拟化、代码高亮、计划与待办、错误条目）已经合并（T085、T143、T226）。本任务做设计 5.7.4 的"回合折叠与用时"和"晚到的输出"。宿主一侧的数据已经齐了：`turn.completed` 带 `final_item_ids`；晚到的工具输出写成 `late_tool_output` 条目；被中断回合里可能仍在运行的命令带 `may_still_run`（5.2.6）。

## 范围

**做**（计划 T146 一行；设计 5.7.4"回合折叠与用时""晚到的输出"、5.3.5）：
1. **按回合折叠与耗时**：
   - 文案和样式照 5.7.4（Codex 样式）："用时 {时长}"、箭头动画、下方边线；
   - 折叠时只留 `final_item_ids` 指向的条目；
   - 始终显示在折叠之外的条目照 5.7.4 的清单：`plan`、`error`、`notice`、`late_tool_output`、请求记录行，还要给改动卡片（T132）留好位置；
   - 运行中的回合不折叠；
   - 折叠状态在行虚拟化里只占一行，向前插入历史后视口不跳动。
2. **晚到的输出**：
   - `late_tool_output` 默认折叠，标"取消后仍在运行"，显示命令和退出码；
   - 点击跳到原条目；
   - 原条目旁显示"最终退出码"。
3. **`may_still_run` 提示**：被中断回合里还在运行的 `execute` 类工具，立刻提示"命令可能仍在运行"。
4. **用例**：
   - UI-stream-fold（已登记）：折叠与展开、用时、始终显示的条目，亮暗两种主题；
   - UI-late-output（已登记）：晚到输出的折叠、跳转、最终退出码。
   - 基线只用 `ui-baseline` workflow 生成，逐张核对；现有基线中只有确实受影响的那几张可以变。
5. 附复刻度审阅截图（e2e 构建、系统字体，不进基线）。

**不做**：回合改动卡片本身（T132）；宿主一侧的改动。
