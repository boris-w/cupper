主要结论，括号里是来源：

- **布局**
  - 窗口默认 1280×820，最小 480×600；顶栏 44px，交通灯位于 (16, 15)；默认开半透明（`vibrancy: menu`）。（本机）
  - 左栏默认 340px，可拖动，范围 240–520，最左是约 52px 的导航栏。截图里左栏被拖窄成约 290pt：导航栏 52pt 加列表 238pt。（本机、截图）
  - 侧边栏行高 30px，圆角 10px。（本机）
  - 会话列最大宽 768px，正文实宽 736px。截图里输入框和用户气泡都是 736.5pt。（本机、截图）
  - 右侧侧边面板贴满高度：最小 320px，给会话区至少留 352px。截图右上那张浮起的卡片其实是 300px 的摘要卡片，不是审查面板。（本机、截图）
- **颜色**
  - 颜色由主题种子推导。Codex 默认种子：亮色 accent #339CFF、前景 #1A1C1F、背景 #FFFFFF、对比度 45；暗色 #339CFF、#FFFFFF（正文实际 #DFDFDF）、#181818、对比度 60。（本机）
  - 我按包里的规则算出了全套语义色。亮色用截图核对了 4 处，都对得上：正文 #191C1F、用户气泡 #F3F3F4、禁用发送按钮 #8C8D8F、选中行 #EBECEC。（本机、截图）
- **字体、圆角、动画**
  - 系统字体，字重 430；界面字号 14，代码字号 12，聊天行高 1.625。（本机）
  - Chromium 155 支持 corner-shape，圆角放大 1.25 倍并用 superellipse：菜单 15px，卡片 20px，输入框和气泡 22px。（本机）
  - 动画时长 150/200/300ms。（本机）
- **组件**
  - 审批和提问不是消息流里的卡片，而是替换输入框位置的请求面板：选项编号、"Recommended" 徽标、自由输入、Skip/Submit、Esc 关闭。（本机；实际渲染位置没有实机确认）
  - 行内评论没有"发给 agent"按钮，评论作为附件进输入框，随下一条消息发出。（本机）
  - 跟进消息默认是 Steer，⌘Enter 排队。（本机）
- **快捷键**：本机注册表和官方表一致。⌘. 被 ChatGPT 占用；中断回合是运行中按两次 Esc。（本机、公开）

第 6 节列了 17 处需要更正的估计、16 个设计里漏掉的元素。改动最大的几条：

## 关键取舍

- **颜色按本机规则自行计算，不照抄样式表。** 运行时颜色是 JS 按种子算出来的，样式表里只有回退值，照抄会错。我自己重算，再用截图核对亮色。截图证明作者用的是 Codex 默认种子，没有走 ChatGPT 强调色那条路径，所以规格按 Codex 默认种子给值，ChatGPT 强调色的情况另外注明。
- **公开物料和本机包冲突时以本机为准。** 官方截图都在 7 月合并之前，权限按钮位置、亮色默认色、代码字号、审批形态都和现在不同。冲突点列在第 7.2 节。
- **建议 token 名沿用 Tailwind v4 的命名空间**（`--color-*`、`--radius-*`、`--text-*`），布局尺寸用 `--layout-*`。只是建议，最终由 T084/T106 定。
- **只记数值和简短文案。** 没有代码块，没有复制样式表、图标、图片、字体。包里的 OpenAI Sans 只记了名字。
