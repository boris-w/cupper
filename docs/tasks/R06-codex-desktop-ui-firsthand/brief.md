# R06 Codex 桌面版界面的一手资料

- 派发日期：2026-10-19
- 执行者：子 agent（调研员，熟悉前端）
- 分支：`research/R06-codex-desktop-ui-firsthand`
- 依赖：无；结果交给 D03（带界面的 PRD）和后面的 T106（视觉规格）

## 背景

复刻 Codex 桌面版的界面，是产品的关键点（PRD UI-6）。R01 的界面拆解没有一手的视觉资料：没有安装 App，也没有截图，配色、字体、间距、比例都是推测。目前只有作者截的一张主界面亮色截图，以及根据它写的观察笔记。

用户本机装了 ChatGPT 桌面 App（Codex 视图就在里面），并同意通过两种途径收集资料：
- 网上的公开物料；
- 静态读取本机 App 里的界面资源。

## 目标

整理出一份 Codex 桌面版界面的一手规格，供 D03 和 T106 使用，内容包括：
- 布局与尺寸；
- 设计参数（颜色、字体、字号、间距、圆角、阴影，以及亮色和暗色两套）；
- 组件清单与结构；
- 关键界面的状态和文案；
- 快捷键。

## 途径与边界（必须遵守）

1. **公开物料**：
   - 官方文档和发布说明（developers.openai.com 的 Codex 部分、help.openai.com、OpenAI 博客）；
   - 评测文章、带截图的教程、视频的文字说明。

   记录 URL 和每张截图里能看到的内容。外发请求不带个人信息，需要时用 `cupper-research` 作占位。
2. **本机 App 的静态读取**：
   - 只读 `/Applications/ChatGPT.app` 这个包。把 `Contents/Resources/app.asar` 解到 `$TMPDIR` 下自建的目录，可以用 `@electron/asar`，也可以按格式自己解析。
   - 读渲染进程里的 CSS（含 CSS 变量和 Tailwind 主题）、HTML、JS 包中的组件和类名结构，以及界面文案和本地化文件。
   - **不启动 App。不读用户数据目录**，包括 `~/Library/Application Support/ChatGPT`、`~/Library/Caches`、`~/.codex`，以及钥匙串和任何会话记录。
   - 不修改 App 包，不改任何系统设置。
3. **版权与开源**：
   - 读取只为了解布局和设计参数。
   - **不把对方的代码、样式表、图标、图片、字体文件复制进仓库**，也不在报告里大段引用代码。
   - 可以记录事实性的数值，例如"侧边栏宽 260px""正文字号 14px""颜色 #0D0D0D"，以及简短的界面文案（按钮、标签），用于描述。
   - 字体只记名称，不分发字体文件。
4. 解包出来的文件只放在临时目录，任务结束前删除，不入库，汇报里也不写临时目录的路径。

## 产出

在任务目录下提交 `ui-spec.md`，用自己的话写，不放截图。内容如下：

1. **来源与版本**：App 版本、资源的位置（只写包内的相对路径）、公开物料的 URL。
2. **布局**：
   - 三栏的尺寸，包括侧边栏宽度、会话区最大宽度、右侧工作区；
   - 标题栏，交通灯按钮的位置；
   - 断点和可以收起的部分。
3. **设计参数**：亮色和暗色的颜色表、字体族、字号阶梯、行高、间距阶梯、圆角、阴影、边框、动画时长。给出原始的变量名，以及我们建议的 token 名。
4. **组件清单**：侧边栏（项目、会话行、状态与未读、操作菜单）、新建会话页、消息流（用户消息、思考、工具活动的单行摘要与分组、命令输出、回合折叠与用时、最终回答、计划与待办、错误）、审批与提问卡片、输入框（底栏的选择器、`@`、斜杠命令、排队、Steer）、审查面板（范围切换、文件列表、diff、hunk 操作、行内评论、提交与推送）、设置页、通知。每个组件写明结构、状态、尺寸和关键文案（英文原文，简短）。
5. **快捷键表**。
6. **与 cupper 设计的差异**：对照 `docs/design/07-desktop.md` 5.7.4（布局常量、组件树）和截图观察笔记，列出哪些估计需要更正，哪些元素是设计里漏掉的。
7. **核实情况**：每条结论标明来源（本机资源、公开物料、推测）。
