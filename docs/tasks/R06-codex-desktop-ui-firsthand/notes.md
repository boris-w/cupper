# R06 过程笔记

## 读取方法

- `app.asar` 用自写的小脚本按格式解析：读取头部的 JSON 索引，只解出 `webview/`、`.vite/build/`、`native-menu-locales/` 和 `package.json`。解到 `$TMPDIR` 下自建的目录，任务结束前已删除。
- 文案：从各 JS 块里按"消息 id 加 defaultMessage"配对出英文原文，再从 `zh-CN-*.js` 取中文，合成一张临时对照表。少数条目的英文配对会错位（id 和 defaultMessage 不在同一个对象里），规格里引用文案时以中文为准，英文只用配对确定的那些。
- 样式：在主样式表里把定义了自定义属性的规则按"所在层、选择器"整理出来，再到 JS 里找运行时写入的变量。
- 没有启动 App，没有读用户数据目录（Application Support、Caches、`~/.codex`、钥匙串、会话记录），没有修改 App 包。

## 颜色是怎么算出来的

- 颜色由主题种子推导：渲染进程按种子（accent、ink、surface、contrast）做线性 RGB 混色，算出 `--app-color-*` 写到 `<html>` 的行内样式上。
- 本任务按包里的混色比例，自己写脚本重算了默认主题亮色和暗色的结果。规格第 3.2 节的数值就是这样来的，带透明度的颜色另外给出叠在背景上的近似实色。
- 亮色结果用作者截图核对过 4 处，都对得上：
  - 正文 #191C1F；
  - 用户气泡 #F3F3F4；
  - 禁用态发送按钮 #8C8D8F；
  - 选中行 #EBECEC。

## 截图测量方法

- 用纯 Python 解码 PNG（2806 × 1742，2 倍屏）。
- 沿若干行和列找颜色突变的位置，得到各区域的边界和颜色，像素值除以 2 折算成 pt。
- 解码结果只放在临时目录，已删除。规格里只写测量值，不写截图内容。
