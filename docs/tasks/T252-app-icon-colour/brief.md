# T252 App 图标颜色

- 派发日期：2026-11-10
- 执行者：子 agent（前端与桌面主进程工程师；T151、T248、T253、T255 的执行者）
- 分支：`feat/T252-app-icon-colour`
- 依赖：T147、T250（都已合并）。不在 M1b 的退出条件里（编号的里程碑是 release）

## 范围

**做**（计划 T252 一行；会议 `docs/meetings/2026-11-10-app-icon/` 的 D1–D4；设计 5.7.2 的 `appIcon`、5.7.4 设置页的"外观"）：

1. **母版随 App 打包**：
   - 六套配色：拿铁、摩卡、晴空、抹茶、墨色、夜色，母版在会议物料 `icon/` 下，每套各有 SVG 和 1024 的 PNG。
   - Dock 图标用 1024 的 PNG，放在 App 包的资源里（`extraResources` 或同类方式），主进程在调用时才读取。
   - 包体增量写进汇报。
2. **prefs 的"图标颜色"**：
   - 键名你定，照 `composer.sendKey` 的写法；默认拿铁。
   - 取值不在六套里的，按默认处理。
3. **主进程 `appIcon` 模块**（设计 5.7.2）：
   - 建窗口之前按 prefs 调一次 `app.dock.setIcon`；
   - prefs 变化时立即更新（照现有 prefs 的 `onChange` 广播）；
   - 选回默认时，恢复 App 包里的图标。
4. **设置 → 外观**：
   - 外观分区还不存在，本任务把它建出来（计划 v1.3.92：第一个往外观里加行的任务建分区）。
   - 在分页表里加一行，位置按设计 5.7.4 排在"通知"之后、"已归档会话"之前。
   - 页里一行"图标颜色"，六个小图标单选，cupper 特有。
   - 说明里写明：只改变 App 运行时 Dock 里的图标；访达、启动台和系统通知里仍是默认图标。
   - 文案走 `@cupper/i18n`。
   - **小图标**：渲染进程受 CSP 限制，只能从 `app://` 加载，所以小图标作为渲染层的静态资源打进去。用缩小后的 PNG 即可，注意包体。
5. **用例**（都已登记）：
   - **UNIT-app-icon-pref**：取值校验与回退；启动时和变更时各设一次 Dock 图标；选回默认时恢复包里的图标。
   - **UI-icon-colour**：外观页的"图标颜色"一行，两种主题，基线只由 `ui-baseline` 生成。
   - 外观分区加进导航后，其他设置页的截图导航会变，一并重新生成。

**不做**（会议 D4）：
- App 没运行时的 Dock 图标（要另写 Dock 插件）；
- 改写 App 包上的图标（和签名、自动更新冲突）；
- 通知图标跟随（系统只在第一次记下）；
- iOS 的图标切换（M3）；
- 外观分区里的其他行：主题和半透明侧边栏归 T152，语言归 T154。
